# Neon Rumble attribution

Face-Off Rumble adapts fighting-game systems (frame data, hitstun/blockstun,
projectiles, pushback, hitstop) inspired by
[hao035414-cmyk/neon-rumble](https://github.com/hao035414-cmyk/neon-rumble)
(MIT License, Copyright (c) 2026 koma).

This module is a TypeScript rewrite for the Face-Off arcade suite (2-player
couch/online, player-face portraits, shared UI patterns). Original Neon Rumble
ships zero Capcom assets — fighters are drawn procedurally.

See `LICENSE` in this folder for the upstream MIT text.
