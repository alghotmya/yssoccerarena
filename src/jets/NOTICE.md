# Space-Jam attribution

Face-Off Jets adapts level data, enemy behaviors, weapon upgrades, bosses,
power-ups, and side-scrolling shmup systems from
[DanMat/Space-Jam](https://github.com/DanMat/Space-Jam) (MIT License,
Copyright (c) 2026 DanMat).

This module is a TypeScript rewrite for the Face-Off arcade suite (procedural
fighter-jet art, player-face cockpit portraits, shared UI). Space-Jam uses
procedural canvas art only (no Capcom / commercial sprites).

See `LICENSE` in this folder for the upstream MIT text.
