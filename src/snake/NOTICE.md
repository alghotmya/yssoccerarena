# Snake.io attribution

Face-Off Snake adapts gameplay concepts and vector-style snake rendering ideas from
[bibhuticoder/snake.io](https://github.com/bibhuticoder/snake.io) (MIT License,
Copyright (c) 2017 Bibhuti Poudyal).

The original is a single-player Slither.io-style canvas demo. This module is a
TypeScript rewrite for local/online 2-player face-off inside the Face-Off arcade suite
(keyboard steering, shared arena, kill scoring, shared UI patterns).

See `LICENSE` in this folder for the full MIT text from the upstream project.
